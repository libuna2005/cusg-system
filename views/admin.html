Attendance Records

Excuse students or a whole class, and upload attendance from a list of IDs. Open a section to use it.

Excuse a Class / Mark No ClassMark a whole class as excused / no class

Two different situations, kept as two different labels so reporting doesn't lump them together: Excused — the class was expected to attend but had a valid reason to miss it (e.g. kept by an instructor for exam review). No Class / Not Required — that section's schedule never overlapped the mandatory window in the first place (e.g. only an 11:00 AM class that day, with mandatory flag ceremony at 7:30–9:00 AM), so it was never actually required. Students who already have a record for that event (present, excused, or no class) are left untouched.

Excuse an Individual StudentExcuse one or more students across several events

Same idea as above, but for specific students instead of a whole section — e.g. one or a few students had a valid, personal reason to miss the event that doesn't apply to their whole class. Has no effect on any student who already has an attendance record (present, excused, or no class) for the selected event.

Student Attendance Dashboard

This is one global switch for the whole student dashboard, not per event — keeps things uniform no matter which session or how many officers are scanning. While locked, every student sees "To Be Posted" instead of a wrong Absent for anything not recorded yet. Fully manual — nothing locks or unlocks on its own. Press "Lock for Students" before you start scanning, and "Unlock for Students" yourself once every officer has finished uploading.
