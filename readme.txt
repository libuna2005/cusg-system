## 📖 Overview

The CUSG Attendance Portal lets student officers scan student QR codes at campus events and records attendance in real time, serving **2,300+ registered students**.

---

## ✨ Features

| | Feature | Description |
|---|---|---|
| 📷 | **QR Scanning** | Fast event check-in using student QR codes |
| 📦 | **Batch Uploads** | Handles multiple officers scanning at the same time |
| 🎯 | **Audience Targeting** | Limit events by year level, course, and section |
| 🔒 | **Attendance Lock** | Global lock control on the student dashboard |
| 📊 | **Population Summary** | Admin panel with student population stats |
| 🖼️ | **Photo Caching** | IndexedDB-based cache for fast photo loading |
